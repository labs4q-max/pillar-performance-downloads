# Install and update Pillar Performance

## Install on Android

1. Open this repository's Releases section in your phone's browser.
2. Choose an available prerelease and read its compatibility notes.
3. Download the APK under Assets.
4. Open the downloaded file.
5. If Android asks, allow that browser or file manager to install apps from this source.
6. Review Android's installation prompts and install.
7. Open Pillar Performance and complete your profile.

Only enable installation permission for the source you are using. You can turn that permission off afterward. Do not bypass a security warning about a suspicious package.

## Update an existing installation

Back up your records using the app's available export option before updating. Install the new APK over the existing app when its package identity and signing certificate are compatible.

Do not uninstall simply to resolve an update error: uninstalling can remove locally stored records. If Android reports a signature or package conflict, report it before proceeding.

## If installation fails

Check that you downloaded an APK, not the Source code ZIP. Read the release's Android-version and processor requirements. Record the exact error, app version, phone model, and Android version when reporting a problem.

## First launch

Profile setup is intended for a new installation or missing profile, not every visit. Grant camera access when you want to scan food barcodes. If a barcode is unknown, online lookup may be needed; manual food entry remains an alternative where available.
