# Pillar Performance

**Build your next level.**

Pillar Performance is an offline-first Android fitness and nutrition app with personalized performance tiers and four dedicated dashboards.

This repository is for Android downloads, release notes, user guides, and testing feedback. Application source code is maintained separately in a private repository.

## Download

Open this repository's **Releases** section and select an available Android prerelease. Under **Assets**, download the `.apk` file.

If no release is listed, an APK has not been published here yet. GitHub's automatically generated source ZIP is not the Android installer.

See [Installation](INSTALL.md) before installing or updating.

## Your dashboards

| Dashboard | What you can do |
| --- | --- |
| Performance | Plan and log workouts, explore the body map and exercise library, and record supported fitness tests. |
| Nutrition | Log food and serving sizes, scan supported barcodes, review calories and macros, and track water. |
| Progress | Review training history, strength results, weight trends, and goals. |
| Account & Settings | Manage your profile, units, appearance, and available data-management options. |

## Personalized performance tiers

Supported strength assessments use relevant profile information and reference standards to place results into performance tiers. These help you follow progress over time. Coverage depends on the exercise and available reference data; missing data should not be treated as a low score.

## Offline first

Your profile and activity records are stored locally. Saved foods and locally available food data support offline logging. Looking up an unfamiliar barcode can require an internet connection; scanning a barcode does not guarantee a matching food record.

Website and Android installations keep separate local records unless you explicitly transfer data through a supported export/import workflow.

## Getting started

1. Install the APK from an available release.
2. Complete your profile when prompted.
3. Choose your preferred units and appearance.
4. Open Performance to train or Nutrition to log food.
5. Review your results in Progress.
6. Use the info icon for help with the current screen.

## Testing status

Pillar Performance is being prepared for early Android testing. Check each release's notes for compatibility, signing details, changes, and known limitations. Real-device testing remains important.

For bugs, open an issue with your app version, device, Android version, steps to reproduce, and expected versus actual behavior. Remove personal information from screenshots and do not attach your private database or backups.
